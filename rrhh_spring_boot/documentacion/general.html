Documentación del Proyecto RRHH MVP

1. Descripción del Proyecto

Este proyecto es un MVP (Producto Mínimo Viable) de un sistema de Recursos Humanos (RRHH). Está diseñado usando una arquitectura basada en Spring Boot 3 con una API de GraphQL. El sistema maneja usuarios, empleados, departamentos, registros de asistencia (incluyendo enrolamiento de reconocimiento facial e IoT), ausencias y generación de preplanillas de sueldo.

2. Flujo de Funcionamiento

  1. Autenticación y Seguridad: Los usuarios acceden y obtienen un JWT, el cual es validado en cada petición.
  2. Gestión de Empleados: Se registran empleados asignándoles un departamento, cargo y horario laboral.
  3. Asistencia e IoT: El sistema puede estar en modo "EMPAREJAR" (para registrar rostros) o "LECTURA" (para asistencia). Las asistencias se marcan enviando un código facial y, opcionalmente, ubicación GPS.
  4. Ausencias: Los empleados solicitan permisos que pasan por un flujo de aprobación.
  5. Preplanillas: Al final de un ciclo, se genera una preplanilla calculando días trabajados, horas extra, faltas y retrasos para calcular el pago, almacenando los reportes en la nube (AWS S3).

4. Cómo Iniciar el Proyecto

Asegúrate de tener Java 17 y PostgreSQL instalados.

  1. Renombra el archivo .env.example a .env.
  2. Modifica las variables en .env para que coincidan con tu servidor local de PostgreSQL.
  3. Abre una terminal en la raíz del proyecto.
  4. Ejecuta el proyecto usando Maven Wrapper: 
    # En Windows
.\mvnw spring-boot:run

# En Linux/Mac
./mvnw spring-boot:run
  5. Accede a la interfaz interactiva de GraphQL en tu navegador: http://localhost:8080/graphiql

5. API y Endpoints (GraphQL)

A diferencia de REST (que tiene muchos endpoints como /api/users o /api/empleados), GraphQL expone un único endpoint principal para todas las operaciones:

POST http://localhost:8080/graphql

¿Cómo comunicarse con el endpoint?

Se debe enviar una petición HTTP POST en formato JSON con la clave query. Ejemplo usando Javascript (Fetch):

fetch('http://localhost:8080/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer TU_TOKEN_JWT'
  },
  body: JSON.stringify({
    query: `
      query {
        empleados {
          content { id nombre apellido }
        }
      }
    `
  })
})
.then(res => res.json())
.then(data => console.log(data));

Operaciones Disponibles

Las operaciones en GraphQL se dividen en Queries (para leer datos) y Mutations (para crear, actualizar o borrar datos).

QUERIES (Consultas)

  • usuarios / usuario(id): Consulta de usuarios del sistema.
  • empleados(page, size, estado, departamentoId): Lista paginada y filtrada de empleados.
  • empleado(id): Detalles de un empleado en particular.
  • departamentos / cargos: Catálogos de la empresa.
  • registrosAsistencia: Historial de entradas y salidas de los empleados.
  • solicitudesAusencia: Lista de solicitudes de permiso o vacaciones.
  • preplanillas: Lectura del cálculo mensual/quincenal de nómina.

MUTATIONS (Acciones)

  • crearEmpleado / actualizarEmpleado / desactivarEmpleado: Gestión del personal.
  • asignarRol / activarUsuario: Gestión de cuentas de acceso al sistema.
  • cambiarEstadoSistema: Permite cambiar entre modo "Registro de Rostro" y modo "Control de Asistencia" para IoT.
  • enrolarRostro: Asigna un código biométrico a un empleado.
  • registrarEntrada / registrarSalida: Almacena las marcaciones enviando coordenadas y biometría.
  • crearSolicitudAusencia / aprobarSolicitudAusencia / rechazarSolicitudAusencia: Flujo de aprobación de permisos.
  • generarPreplanilla: Procesa la asistencia y genera la preplanilla para pagos.
